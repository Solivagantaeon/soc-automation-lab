## 1. VM creation (Proxmox API)

### 1.1 Make the cloud image importable

Proxmox only imports disk images from storage with the `import` content type, so the `local` storage got this content type added and the official Ubuntu cloud image was downloaded into it:

| Step | Value |
|---|---|
| Storage `local` content | `vztmpl,snippets,iso,backup` → `vztmpl,snippets,iso,backup,import` |
| Image source | `https://cloud-images.ubuntu.com/noble/current/noble-server-cloudimg-amd64.img` |
| Saved as | `local:import/noble-server-cloudimg-amd64.qcow2` (`/var/lib/vz/import/`) |

The image can be reused for further Linux VMs.

## 2. Agent installation

Command generated by Wazuh Dashboard → **Agents → Deploy new agent → DEB amd64** (server `10.10.20.243`, name `SOC-LIN-01`), run on SOC-LIN-01:

```bash
wget https://packages.wazuh.com/4.x/apt/pool/main/w/wazuh-agent/wazuh-agent_4.14.9-1_amd64.deb \
  && sudo WAZUH_MANAGER='10.10.20.243' WAZUH_AGENT_NAME='SOC-LIN-01' \
     dpkg -i ./wazuh-agent_4.14.9-1_amd64.deb

sudo systemctl daemon-reload
sudo systemctl enable wazuh-agent
sudo systemctl start wazuh-agent
```

Result: package downloaded from `packages.wazuh.com` (internet access from VICTIM works), `wazuh-agent 4.14.9-1` installed, service enabled. The agent auto-enrolled and joined group `default` (no group variable needed).
